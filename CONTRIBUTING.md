# Contributing to CraftCopy AI

Thanks for helping improve CraftCopy AI.

## Before opening a pull request

1. Open an issue for large changes so the scope can be discussed.
2. Keep generated copy grounded in seller-provided facts.
3. Do not add paid API requirements to the default workflow.
4. Run `pytest -q` and include tests for behavior changes.
5. Never commit credentials, private customer data, or model weights.

## Good first contributions

- Add category-specific input examples.
- Improve keyboard navigation and screen-reader labels.
- Add CSV or Markdown export.
- Create a repeatable evaluation set for factuality and editing time.
- Improve local inference documentation for CPU-only machines.
